# PRD — 제품 요구사항 정의서

## 1. 제품 개요

| 항목 | 내용 |
|------|------|
| 제품명 | Kanban Board |
| 버전 | 2.0.0 |
| 작성일 | 2026-05-20 |
| 작성자 | yuuny05 |

드래그 앤 드롭으로 작업 카드를 관리할 수 있는 3-컬럼 칸반 보드 웹 앱이다. Supabase Auth로 사용자 인증을 지원하고, Supabase PostgreSQL에 카드 데이터를 사용자별로 영속 저장한다.

---

## 2. 목표

- 작업 항목을 빠르게 추가·삭제하고 상태를 한눈에 파악한다.
- 마우스 드래그만으로 컬럼 간 이동이 가능하여 조작 마찰을 최소화한다.
- Supabase BaaS를 통해 사용자 인증과 카드 데이터 영속화를 지원한다.
- 이메일/비밀번호, Google, GitHub 세 가지 방법으로 로그인할 수 있다.

---

## 3. 사용자

| 페르소나 | 설명 |
|----------|------|
| 개인 개발자 | 개인 프로젝트 태스크를 어디서든 접근 가능한 클라우드 칸반으로 관리하고 싶은 사람 |
| 수강생 | 과제·스터디 진행 상황을 시각화하려는 코딩 부트캠프 참가자 |

---

## 4. 기능 요구사항

### 4.1 핵심 기능 (Must-have)

| ID | 기능 | 설명 |
|----|------|------|
| F-01 | 3-컬럼 보드 표시 | To-do, In-Progress, Done 컬럼을 가로로 나란히 표시 |
| F-02 | 카드 추가 | 각 컬럼 하단 입력창에 텍스트 입력 후 버튼 클릭 또는 Enter로 카드 생성 |
| F-03 | 카드 삭제 | 카드 우측 상단 × 버튼 클릭으로 카드 제거 |
| F-04 | 드래그 앤 드롭 이동 | HTML5 Drag & Drop API로 카드를 다른 컬럼으로 이동 |
| F-05 | 드래그 시각 피드백 | 드래그 중인 카드 반투명 처리, 드롭 대상 컬럼 하이라이트 |
| F-06 | 이메일/비밀번호 인증 | 이메일과 비밀번호로 회원가입 및 로그인 |
| F-07 | Google OAuth 로그인 | Google 계정으로 소셜 로그인 |
| F-08 | GitHub OAuth 로그인 | GitHub 계정으로 소셜 로그인 |
| F-09 | 로그아웃 | 헤더의 로그아웃 버튼으로 세션 종료 |
| F-10 | 카드 데이터 영속화 | 로그인한 사용자의 카드를 Supabase PostgreSQL에 저장, 새로고침 후에도 유지 |
| F-11 | 사용자별 데이터 격리 | 각 사용자는 자신의 카드만 볼 수 있음 (RLS 적용) |

### 4.2 선택 기능 (Nice-to-have, v2.1 이후)

| ID | 기능 |
|----|------|
| F-12 | 카드 편집 — 더블클릭으로 텍스트 인라인 수정 |
| F-13 | 컬럼별 카드 수 뱃지 표시 |
| F-14 | 모바일 터치 드래그 (Touch Events) |

## 5. 비기능 요구사항

| 항목 | 기준 |
|------|------|
| 브라우저 지원 | Chrome 90+, Firefox 88+, Edge 90+ |
| 응답성 | 드래그 이벤트 지연 없음 |
| 의존성 | Supabase JS v2 (CDN) 외 외부 라이브러리 없음 |
| 파일 분리 | HTML / CSS / JS 반드시 별도 파일 |
| 실행 환경 | `python3 -m http.server` 로컬 서버 또는 정적 호스팅 |
| 보안 | RLS로 사용자별 데이터 격리, anon key만 클라이언트에 노출 |

## 6. 사용자 스토리

```
As a 사용자,
I want to Google 또는 GitHub 계정으로 간편하게 로그인하고 싶다,
So that 별도 비밀번호 없이 칸반 보드를 사용할 수 있다.

As a 사용자,
I want to 새 카드를 컬럼에 추가하고 싶다,
So that 할 일을 기록할 수 있다.

As a 사용자,
I want to 카드를 드래그해 다른 컬럼으로 옮기고 싶다,
So that 작업 진행 상태를 시각적으로 표현할 수 있다.

As a 사용자,
I want to 브라우저를 새로고침해도 카드가 유지되길 원한다,
So that 작업 내역을 잃지 않을 수 있다.
```
